HMS Personal AI Agent — ابتدائی ویب ایپ پروٹوٹائپ

اہم فائلیں:
index.html — مرکزی صفحہ
style.css — ڈیزائن
app.js — ابتدائی انٹرفیس، مقامی ٹاسک لسٹ اور ڈیمو چیٹ
manifest.json — انسٹال ایبل ویب ایپ کی معلومات
sw.js — بنیادی آف لائن کیش
icon-192.png اور icon-512.png — ایپ آئیکنز
icon.svg — براؤزر آئیکن

اہم حدود:
یہ ابھی حقیقی AI سے منسلک نہیں ہے۔ حقیقی AI چیٹ، لائیو جاب سرچ، لاگ اِن، کلاؤڈ سنک اور محفوظ بیک اینڈ شامل نہیں۔ اسے صرف HTML/CSS/JavaScript فائلوں کے طور پر ہوسٹ کیا جا سکتا ہے۔ GitHub Pages پر پبلش کرنے سے پہلے تمام فائلیں repository کے root میں اپلوڈ کریں۔
